## Структура

- `index.html` - лендинг
- `privacy.html` - Политика обработки ПДн (152-ФЗ, с плейсхолдерами реквизитов)
- `assets/horizon-bg.svg` - фон hero без дубляжа логотипа текстом
- `assets/team/` - фото команды
